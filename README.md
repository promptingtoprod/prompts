# Prompt to Prod — prompt kits

The prompts, design files and sample data from the [Prompt to Prod](https://www.youtube.com/@promptingtoprod)
videos. Everything here is plain text. Copy a prompt into Claude Code — or any capable AI
coding assistant — and you get the thing from the video.

No account, no signup, nothing to install to read these.

## The kits

| Kit | What you build | Video |
|---|---|---|
| [portfolio-tracker](portfolio-tracker/) | A private portfolio dashboard that runs on your own computer. Reads your broker's CSV export, shows live prices and what moved your money today. | *link on publish* |

## How to get the files

**One kit.** Open its folder above, click a file, then the **Download raw file** button.

**All of it.** Green **Code** button at the top of this page → **Download ZIP**. The whole
repository is a few dozen kilobytes of text.
